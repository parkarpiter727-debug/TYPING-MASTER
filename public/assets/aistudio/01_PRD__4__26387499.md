# 01 — Product Requirements Document (PRD)
## Project: TypeMaster Pro — Bilingual Typing Master (English + Urdu)

---

## 1. Project Overview

**Product Name:** TypeMaster Pro  
**Type:** Web Application (Browser-based, no install required)  
**Languages Supported:** English & Urdu (toggle switch)  
**Goal:** A professional, visually advanced typing practice platform that helps users improve their typing speed and accuracy in both English and Urdu, with progress tracking and global leaderboards.

---

## 2. Target Users

| User Type | Description |
|-----------|-------------|
| Student | School/college student learning to type in English or Urdu |
| Professional | Office worker wanting to improve typing speed |
| Casual Learner | Anyone who wants to practice typing for fun |
| Competitive Typist | User who wants to rank on the leaderboard |

---

## 3. User Roles

| Role | Access |
|------|--------|
| Guest | View home page, try one sample test only |
| Registered User | Full access: all lessons, tests, progress, leaderboard |

---

## 4. Core Features

### 4.1 Language Toggle
- Prominent button (top navbar) to switch between **English** and **Urdu** modes
- Switching language changes: keyboard layout hint, lesson content, font (Nastaliq for Urdu), text direction (RTL for Urdu, LTR for English)
- User's language preference is saved in their profile

### 4.2 Typing Lessons (3 Levels)

**Beginner**
- Home row keys (ASDF JKL;)
- Individual finger drills
- Simple 3–5 letter words
- Urdu: basic characters (ا ب پ ت ٹ ث)

**Intermediate**
- Full keyboard usage
- Common word lists (500 most used words)
- Sentence typing
- Urdu: common words and sentences

**Advanced**
- Paragraphs and long passages
- Speed-focused drills
- Accuracy under pressure
- Urdu: newspaper/professional text passages

### 4.3 Custom Lesson
- User pastes their own text (English or Urdu)
- App turns it into a typing session
- Results saved to their history

### 4.4 Typing Test
- Timed tests: **1 min / 2 min / 5 min** options
- Real-time display: current WPM, accuracy %, error count
- After test: full result screen with:
  - WPM (Words Per Minute)
  - Accuracy %
  - Errors count
  - Time taken
  - Characters typed
  - Improvement vs last test (+ / -)
- Option to retry same test or try new one

### 4.5 Real-Time Typing Interface
- Text display area: upcoming text shown clearly
- Current character highlighted
- Correctly typed characters: green
- Incorrectly typed characters: red
- Cursor blinking at current position
- Virtual keyboard (optional display) showing which key to press next
- Backspace support

### 4.6 User Dashboard
- Personal stats: best WPM, average WPM, average accuracy
- Progress chart: WPM over last 30 days
- Lessons completed count
- Tests taken count
- Streak (consecutive days practiced)
- Language breakdown (English vs Urdu sessions)

### 4.7 Leaderboard
- Global leaderboard: top 100 users by best WPM
- Separate tabs: English leaderboard / Urdu leaderboard
- User's own rank shown even if not in top 100
- Weekly reset option (optional: all-time + this week tabs)

### 4.8 User Authentication
- Sign up with email + password
- Login / Logout
- Profile page: change display name, avatar (initials-based), preferred language
- Password reset via email

---

## 5. Business Rules

1. Guest users can only attempt **1 sample test** — then prompted to sign up
2. Leaderboard shows only registered users
3. Custom lesson text must be **minimum 50 characters**
4. Test results are only saved if user is **logged in**
5. Urdu mode requires **Noto Nastaliq Urdu** font to be loaded
6. WPM calculation: `(characters typed / 5) / minutes elapsed`
7. Accuracy calculation: `(correct characters / total characters typed) × 100`

---

## 6. Non-Functional Requirements

| Requirement | Specification |
|-------------|---------------|
| Performance | App loads in under 3 seconds |
| Responsive | Works on desktop, tablet, mobile |
| Browser Support | Chrome, Firefox, Edge, Safari (latest 2 versions) |
| Availability | 99.9% uptime via Cloudflare |
| Security | Supabase RLS on all tables, no keys in frontend |
| Accessibility | WCAG AA — keyboard navigable, sufficient contrast |
| Font | Noto Nastaliq Urdu for Urdu, Inter/JetBrains Mono for English |

---

## 7. Scope

**In Scope:**
- Web app (React + TypeScript)
- English + Urdu typing lessons and tests
- User accounts, progress, leaderboard
- Custom lesson feature
- Dark/Light theme with professional advanced look

**Out of Scope:**
- Mobile app (iOS/Android)
- Admin panel
- Paid plans / subscriptions
- Video lessons
- Voice typing
