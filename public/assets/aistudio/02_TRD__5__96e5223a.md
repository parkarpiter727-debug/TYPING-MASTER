## 4. Supabase Integration Strategy

- Supabase client initialized in `src/lib/supabase.ts` using environment variables only
- All DB calls go through typed helper functions — no raw SQL in components
- Supabase Auth session managed via `onAuthStateChange` listener in `authStore.ts`
- All tables protected by **Row Level Security (RLS)** — see Backend Schema
- **Never** expose `service_role` key in frontend

---

## 5. Authentication Approach

| Feature | Implementation |
|---------|---------------|
| Sign Up | Supabase Auth `signUp()` with email + password |
| Login | Supabase Auth `signInWithPassword()` |
| Logout | Supabase Auth `signOut()` |
| Session | Stored in localStorage by Supabase, auto-refreshed |
| Password Reset | Supabase Auth `resetPasswordForEmail()` |
| Protected Routes | Custom `PrivateRoute` wrapper — redirect to `/login` if no session |

## 7. Language & RTL Strategy

- Global language state stored in `themeStore` (Zustand) + `localStorage`
- When language = `urdu`:
  - `dir="rtl"` set on `<html>` tag
  - Font family switched to `Noto Nastaliq Urdu`
  - Lesson content pulled from Urdu dataset in `lessonData.ts`
  - Keyboard hint shows Urdu character layout
- When language = `english`:
  - `dir="ltr"` on `<html>`
  - Font: `Inter` for UI, `JetBrains Mono` for typing area
  - Lesson content pulled from English dataset

## 8. Typing Engine (Core Logic — `useTyping.ts`)

```typescript
// Key calculations:
WPM = (correctChars / 5) / (elapsedSeconds / 60)
Accuracy = (correctChars / totalTypedChars) * 100
Errors = totalTypedChars - correctChars

// State tracked per session:
- originalText: string
- typedText: string
- currentIndex: number
- correctChars: number
- errorPositions: Set<number>
- isComplete: boolean
- startTime: Date | null
```

## 10. Environment Variables

All variables must be prefixed with `VITE_` and **never hardcoded**:

```env
VITE_SUPABASE_URL=https://your-project.supabase.co
VITE_SUPABASE_ANON_KEY=your-anon-key
```

Set in:
- Local: `.env.local` (gitignored)
- Production: Cloudflare Pages → Settings → Environment Variables

---

## 11. Security Requirements

- RLS enabled on ALL Supabase tables
- `service_role` key never in frontend or GitHub
- Input sanitization on custom lesson text
- No XSS vectors in typing display (text rendered as characters, not HTML)
- CORS handled by Supabase defaults
- Auth tokens never logged to console in production

---

## 12. Cloudflare Deployment Requirements

- Build command: `npm run build`
- Output directory: `dist`
- Node version: 18+
- SPA fallback: `public/_redirects` file with `/* /index.html 200`
- Root `.npmrc` with `legacy-peer-deps=true`
- No `bun.lock` or `bun.lockb` in repo (use `package-lock.json` only)
- Environment variables set in Cloudflare before first deploy

---

## 13. Performance Targets

- First Contentful Paint: < 1.5s
- Typing engine response: < 16ms (60fps)
- Leaderboard load: < 1s (paginated, 20 per page)
- Font preloading: Urdu font preloaded on app init to avoid FOUT
